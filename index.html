Overview

How Cloud's ACO works

Cloud's ACO runs checkout tools for limited releases. Members provide profiles in a correctly formatted Hidden CSV. Staff load the profiles, run the drop, and invoice successful checkouts.

Drop gets announced

Staff post the product, deadline, and Hidden CSV requirement.

Prepare your CSV

Fill the Hidden template carefully. Keep column names unchanged and avoid extra columns.

Upload through DM

Send your CSV only to Cloud's ACO Bot in DMs. The bot checks headers and field values.

Opt into the drop

Click the opt-in button before the deadline so staff can load your latest file.

Pay after success

If a checkout lands, you receive a PAS invoice and pay before the deadline.

Before uploading

Hidden CSV checklist

Run through this before sending your file to Cloud's ACO Bot. Most upload errors come from small formatting mistakes.

✅ Must be correct

  • The file is saved as .csv.
  • Every Hidden column is present.
  • No column names have been renamed.
  • Country fields say exactly GB.
  • Card year uses four digits, like 2027.
  • Card month uses two digits, like 06.

🚫 Avoid these mistakes

  • Uploading an Excel file like .xlsx.
  • Adding blank columns or blank headers.
  • Using United Kingdom instead of GB.
  • Using 6 instead of 06.
  • Using 27 instead of 2027.
  • Posting CSV files in public channels.

After success

PAS invoices

After a successful checkout, Cloud's ACO may invoice a Profit After Sale percentage. Pay the invoice before the deadline shown in your DM.

Example

Retail price: £69.99
Resale value: £120.00
Profit: £50.01
PAS at 25%: £12.50

Reminder

Only pay using the details provided by staff or the official bot. If anything looks wrong, open a ticket before sending payment.

Help

FAQ

Is this guide Hidden-only?

Yes. This final version is focused on Hidden CSV only.

What if my CSV has the wrong columns?

The bot should reject it and explain which columns are missing, extra, or misspelled. Download a fresh Hidden template and copy your data into it.

Should I jig before uploading?

Use the jig bot if you have access and staff recommend it for the drop. Check the output file before uploading it.

Where should I upload my CSV?

Only upload it through Cloud's ACO Bot in DMs. Never post CSV files in public channels.
