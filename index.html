# getting-started

🚀 Getting Started

JC's ACO is an Auto Checkout Operation for limited-release products such as sneakers, Pokémon cards and fashion drops. Members provide correctly formatted profile CSV files, then staff run the bot for selected drops.

Staff announce a dropThe server post shows the product, deadline and required CSV format.
Upload your CSV via DMThe submission bot validates your file and stores it in one of your slots.
Opt inClick the drop button. Your saved CSV is copied to staff automatically.
Bot runsStaff load your profiles and attempt checkout when the drop goes live.
Invoice and paymentIf successful, you receive a PAS invoice with payment details.
✅
No personal bot required

Members only need correctly completed CSV files. JC's ACO handles the bot setup and running process.

# key-terms

📖 Glossary

ACO

Auto Checkout Operation — bot-powered purchase attempts.

Profile

One CSV row containing name, address, email and payment fields.

CSV

Comma-Separated Values file. Bots read this like a spreadsheet.

Jig

Small profile variations so rows appear more unique.

PAS

Profit After Sale — the percentage owed after a successful checkout.

Opt In

Registering your saved CSV for a specific drop.

# csv-basics

📄 What is a CSV?

A CSV is a spreadsheet saved as plain text. Each row is one checkout profile. Fill in the correct template, save as .csv, and upload it in DMs to the official submission bot.

⚠️
Security warning

Never post CSVs in public channels and never upload files containing real card data to a public GitHub repository.

🕵️ Hidden

camelCase columns · Country GB · Expiry year YYYY

⚡ Cyber

Spaced column names · Country United Kingdom · Expiry year YYYY

🌟 Stellar

UPPER_CASE columns · Country GB · Expiry year YY

# profile-jigging

🔀 What is Jigging?

Jigging creates small variations in each profile row so the data looks more unique. Names and address formatting may change; postcodes, emails and card details should not be changed.

🟢 Light

Minimal changes for lower-security sites.

🟡 Medium

Balanced changes. Recommended default for most drops.

🔴 Heavy

Maximum variation for stricter retailers.

# frequently-asked

❓ FAQ

What if I use the wrong CSV format?
The submission bot should validate your upload and explain the exact row, column and value that needs fixing.
Can I update my CSV after opting in?
Yes. Upload the corrected CSV before the deadline and opt in again if staff require it.
Should I jig my CSV before uploading?
Yes, if you have a Jig Bot license. Upload the final jigged output file to the submission bot.
My CSV will not upload — what should I check?
Check the file is a CSV, the headers match the template exactly, there are no blank headers, and required fields are filled.
Is card data safe?
Only use the official bot DM and never upload CSVs publicly. Do not put real card CSVs into GitHub or any public website.
